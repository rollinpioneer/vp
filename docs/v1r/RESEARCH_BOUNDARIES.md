# V1-R 研究边界

本文件只允许记录门槛已经支持的主张。当前新门槛尚未全部运行，以下内容是冻结的可声明条件和禁止越界的解释。

## 可以声明的内容

只有对应门槛通过后，才允许声明：

- 受控目标物体部分遮挡降低指定 Point Bridge 基线表现；
- 下降主要发生在运动或抓持物体阶段；
- Oracle 恢复支持“视觉任务点缺失是原因之一”，但不等同于方法收益；
- 真实视觉前端出现可量化的旧点、漂移、低置信或身份错配；
- 固定点预算下，环境约束点帮助区分任务点相同但正确动作不同的布局；
- 动作条件选点在同预算、同历史、同计算口径下优于普通采样。

## 不允许声明的内容

- Point Bridge 默认仿真天然存在旧点问题；
- CoTracker 一定频繁更新错点；
- 所有遮挡都能由记忆解决；
- 第一帧完全不可见的物体仍应被准确抓取；
- 动态选点在信息论上优于完整点云；
- 新方法首次输入环境点或机器人状态；
- 增加点数、相机数或模型参数后的提升属于固定预算收益；
- 方法保证无碰撞或安全；
- P 级仿真结果等同于 V 级真实视觉结果；
- Oracle 结果可以作为正式可部署方法结果。

## 必须分开报告

静止物体与运动物体、GT 与真实视觉点、外部/腕部/多视角、5/10/20 Hz 感知更新、任务对象点与完整场景点、同预算与高预算上界、图像遮挡与三维实体遮挡/自遮挡，均不得混成单一结果。

## 当前状态

V1-R.0/V1-R.1 的代码和协议修复不授权 V2/V3 正式实验。授权必须来自 `v1r_decision.yaml`，并与 `configs/stage_status.yaml` 一致。
